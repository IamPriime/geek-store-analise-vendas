# Dados de demonstração

Este CSV é **fictício**, criado para demonstrar e testar o código. Não é o dataset original do Colab e não sustenta conclusões sobre vendas, artistas ou corridas reais.

Para usar seus dados, substitua o CSV preservando as colunas do cabeçalho. Use números sem símbolos de moeda. Capacidade de local deve ser maior que zero; posições devem ser positivas.
